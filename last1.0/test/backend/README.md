## 📦 快速开始

### 安装依赖

```bash
cd yuyi_pro_v2
pip install -r requirements.txt
```

### 运行测试

```bash
python yuyi_pro.py
```

### API使用

```python
from yuyi_pro import YuyiPro
import asyncio

async def create_my_video():
    yuyi = YuyiPro()

    result = await yuyi.create_video(
        topic="你的主题",
        target_duration=180,  # 3分钟
        total_budget=100.0,   # 预算100元
        quality_priority=True
    )

    print(f"成功生成: {result['stats']['success_count']} 个分镜")
    print(f"爆款分数: {result['stats']['viral_score']:.1f}/100")
    print(f"输出目录: {result['output_dir']}")

asyncio.run(create_my_video())
```

## 🎨 支持的11个视频模型

### Sora2系列 (OpenAI)
- **sora2-new**: 表情自然，适合人物口播
- **sora2-pro**: 超高质量，适合核心场景

### Veo3系列 (Google)
- **veo3.1-pro**: 4K画质，产品细节
- **veo3.1**: 高质量场景
- **veo3.1-fast**: 快速生成，过渡场景

### 其他模型
- **jimeng**: 中文场景优化
- **runway**: 专业后期特效
- **kling**: 高帧率运动
- **vidu**: 性价比之选
- **pixverse**: 超低成本

## 🔧 配置说明

### 修改API密钥

编辑 `config.py`:

```python
SUCHUANG_API_KEY = "你的密钥"
```

### 调整并发数

```python
MAX_CONCURRENT_SUBMISSIONS = 50  # 最大同时提交数
MAX_CONCURRENT_DOWNLOADS = 10    # 最大同时下载数
```

```python
result = await yuyi.create_video(
```
