## 🐛 常见问题排查

### 问题1：API测试失败

**症状**：
```
❌ 测试失败
错误信息: 401 Unauthorized
```

**解决**：
1. 检查API Key是否正确
2. 检查网络连接
3. 确认API余额充足

### 问题2：服务器启动失败

**症状**：
```
ModuleNotFoundError: No module named 'fastapi'
```

**解决**：
```bash
pip install -r requirements.txt
```

### 问题3：页面加载空白

**解决**：
1. 打开浏览器控制台（F12）
2. 查看Console错误
3. 查看Network请求是否失败
4. 检查 logs/webapp.log

### 问题4：关键帧生成卡住

**症状**：进度条一直显示「生成中」

**解决**：
1. 查看服务器日志
2. 检查是否有错误信息
3. 检查网络连接
4. 重新刷新页面

### 问题5：WebSocket连接失败

**症状**：
```
WebSocket错误: Connection failed
```

**解决**：
1. 检查防火墙设置
2. 确认端口8080未被占用
3. 查看服务器日志

### 问题6：图片无法加载

**症状**：九宫格中图片显示灰色占位符

**解决**：
1. 检查图片URL是否正确
2. 在浏览器中直接打开图片URL
3. 检查网络连接
4. 查看keyframes目录是否有文件
